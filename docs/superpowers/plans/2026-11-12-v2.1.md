# Sirah Mute v2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clickable mute pill, cough-hold on the hotkey, pills for other watched mics, and `--mute/--unmute/--status` for HASS Agent.

**Architecture:** All runtime work stays in the existing single-thread core (`app.rs` state + message loop). New config fields flow settings → `config.json` → `MSG_RELOAD` → `app::diff`. Overlay windows that must take clicks drop `WS_EX_TRANSPARENT` and rely on per-pixel alpha for pass-through. CLI talks to the core through one new registered message answered via `SendMessageTimeoutW`.

**Tech Stack:** Rust (edition per `kuromute/Cargo.toml`), `windows` crate (Win32, Core Audio, D2D/DWrite), Slint settings UI.

**Spec:** `docs/superpowers/specs/2026-11-12-v2.1-design.md`

## Global Constraints

- Run every cargo command from inside `kuromute/` (MSVC pin is cwd-based).
- No new crates.
- Core RAM < 10 MB; hotkey→indicator `latency_ms` p95 < 16 ms (measured from the log, as in v2.0).
- Core never initializes Slint; UI code lives only under `src/settings/` and `ui/settings.slint`.
- Nothing that takes clicks may take focus: keep `WS_EX_NOACTIVATE` and `WM_MOUSEACTIVATE → MA_NOACTIVATE`.
- Border strips stay `WS_EX_TRANSPARENT` + `HTTRANSPARENT`.
- Every new user-visible string has EN and ID in `i18n.rs`.
- Old `config.json` without the new fields must load to defaults (`#[serde(default)]` already on `Config`).
- Never run the no-arg core while the user's installed instance is running. CLI flags (`--status` etc.) are safe: they only message the running core.
- Commits: one per topic, no AI attribution lines.
- `cargo test` and `cargo clippy --all-targets` clean at the end of every task.

## Review Focus

1. Pill shows "Mic on" after unmute → clicks in that ~1.5 s must reach the game (hit-test transparent while unmuted). Test in Task 3.
2. Settings reload or exit while the hotkey is held in cough mode → timer killed, no stray unmute later. Covered in Task 4 Step 3 (clear in `reload`/`exit`/pause) and manual test.
3. Other mic unplugged while its pill is shown → pill disappears on the next device rewatch; a click on a stale index must not touch the wrong mic. Test in Task 5 (`click_index_out_of_range_is_ignored`).
4. `--status` while the core's state is borrowed (tray menu open) → answers from cache, never `not_running`. Test in Task 7 (`status_code_from_cache`).
5. Hand-edited config with 10 duplicate other mics and 40-char names → sanitized to ≤ 6 unique, names ≤ 16 chars. Test in Task 1.
